# Molecular Dynamics

Интерактивная двумерная симуляция частиц на C++ и SFML. Частицы взаимодействуют по потенциалу Леннарда — Джонса; движение интегрируется методом Velocity Verlet с фиксированным шагом времени.

## Управление

- Зажмите левую кнопку мыши, перетащите указатель и отпустите, чтобы добавить частицу. Направление и длина перетаскивания задают её начальную скорость.
- Колесо мыши меняет масштаб камеры.

## Текущий статус

- Исходный код приложения находится в `src/` и `include/`.
- Скрипт `tests/energy_test/energy_test.py` — отдельный эксперимент для пары частиц; папка `tests/momentum_conservation/` пока содержит незавершённую заготовку.
- Для приложения нужна SFML 3. В репозитории пока нет конфигурации сборки, поэтому команды сборки здесь не приводятся.
- Готовые исполняемые файлы не включаются в публикацию.
