# Molecular Dynamics

Интерактивная 2D-симуляция частиц на C++ и SFML. Частицы создаются мышью, взаимодействуют по обрезанному потенциалу Леннарда — Джонса, а их движение рассчитывается методом Velocity Verlet.

## Возможности

- Создание частицы перетаскиванием мыши: точка нажатия задаёт позицию, направление и длина жеста — начальную скорость.
- Масштабирование камеры колёсиком и её перемещение правой кнопкой мыши.
- Отображение скорости цветом и средней полной энергии системы.
- Отражение частиц от границ области `20 × 20`.
- Клеточный список соседей с skin-радиусом для ускорения расчёта сил.

## Физическая модель

Потенциал Lennard–Jones:

\
$$V(r) = 4\varepsilon \left[ \left(\frac{\sigma}{r}\right)^{12} - \left(\frac{\sigma}{r}\right)^{6} \right]$$.


Для конечного радиуса взаимодействия используется force-shifted форма: и потенциальная энергия, и сила плавно обращаются в ноль при отсечении. Это уменьшает скачки энергии при пересечении радиуса отсечения, но немного меняет исходный полный Lennard–Jones потенциал.

| Параметр | Значение по умолчанию |
|---|---:|
| `epsilon` | `1.0` |
| `sigma` | `1.0` |
| Шаг интегрирования | `0.001` |
| Радиус отсечения | `2.5 × sigma` |
| Skin | `0.3 × sigma` |
| Радиус списка соседей | `2.8 × sigma` |

Velocity Verlet использует ускорения в начале и конце временного шага. Массы и координаты задаются в условных единицах симуляции, не в единицах СИ.

## Как ускорен расчёт пар

Область разбивается на прямоугольные клетки. При перестройке списка каждая частица помещается в одну клетку; для неё проверяются только частицы из соседних клеток. В список один раз добавляются пары на расстоянии меньше `cutoff + skin`, после чего силы считаются только для пар ближе cutoff.

Список переиспользуется между шагами. Он перестраивается, когда частица сместилась от своего положения в момент построения на `skin / 2` или больше. Добавление частицы и изменение `sigma` также требуют перестройки. При примерно равномерной плотности это сокращает среднее число проверяемых пар; в очень плотном скоплении худший случай всё ещё может приближаться к `O(N²)`.

## Сборка на Windows

Нужны MSYS2 UCRT64, компилятор MinGW-w64 и SFML 3. В терминале **MSYS2 UCRT64** установите пакеты:

```bash
pacman -S --needed mingw-w64-ucrt-x86_64-gcc mingw-w64-ucrt-x86_64-sfml
```

Из корня проекта соберите и запустите приложение:

```bash
g++ -std=c++17 -O2 -Iinclude src/main.cpp src/Renderer.cpp \
    -o MolecularDynamics.exe -lsfml-graphics -lsfml-window -lsfml-system
./MolecularDynamics.exe
```

Подпись энергии использует системный шрифт `C:/Windows/Fonts/arial.ttf`. Если его нет по этому пути, симуляция работает без текстовой подписи.

## Структура

- `include/ParticleSystem.hpp` — клеточная сетка, список соседних пар, энергия и Velocity Verlet.
- `include/LennardJones.hpp` — потенциал и сила Lennard–Jones, включая force-shifted вариант.
- `include/Particle.hpp`, `include/Vec2.hpp` — состояние частицы и двумерный вектор.
- `include/Renderer.hpp`, `src/Renderer.cpp` — окно SFML, ввод и отрисовка.
- `src/main.cpp` — цикл приложения и параметры симуляции.
- `tests/energy_test/energy_test.py` — отдельный Python-эксперимент для пары частиц; он не проверяет C++ реализацию.

Готовые `.exe` в репозиторий не входят. Пошаговый порядок публикации изменений на GitHub описан в [GITHUB_WORKFLOW.md](GITHUB_WORKFLOW.md).
