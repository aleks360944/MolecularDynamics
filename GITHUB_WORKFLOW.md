# Публикация изменений на GitHub

В проекте настроена ветка `main`, связанная с `origin/main`. Чтобы опубликовать свои изменения:

1. Сохраните файлы в редакторе.
2. Откройте PowerShell в папке проекта.
3. Проверьте, что именно изменено:

   ```powershell
   git status
   git diff
   ```

4. Добавьте нужные файлы. Для публикации всех текущих изменений:

   ```powershell
   git add -A
   ```

   Если нужно включить только часть изменений, перечислите файлы вместо `-A`.

5. Создайте коммит с коротким описанием:

   ```powershell
   git commit -m "Описание изменений"
   ```

6. Получите последние изменения с GitHub и отправьте коммиты:

   ```powershell
   git pull --rebase origin main
   git push origin main
   ```

7. Убедитесь, что публикация завершилась:

   ```powershell
   git status
   ```

   В норме рабочее дерево чистое, а ветка `main` синхронизирована с `origin/main`.

Если `pull --rebase` остановился на конфликте, Git укажет конфликтующие файлы. Откройте их, разрешите отмеченные участки, затем выполните `git add <файл>` и `git rebase --continue`. После завершения повторите `git push origin main`. Не используйте `git push --force` для обычной публикации.

Для короткой просьбы Codex в дальнейшем достаточно написать: «Проверь изменения, создай коммит и отправь на GitHub». Укажите отдельной фразой, если какие-то файлы нельзя публиковать.
